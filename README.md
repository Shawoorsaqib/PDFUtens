## 🚀 About

**PDFUtens** is a lightweight web application that provides essential PDF utilities in one place. It is designed to be simple, secure, and fast, allowing users to manipulate PDF files directly from their browser.

The project is built using **Flask** for the backend and **HTML, CSS, and JavaScript** for the frontend.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Shawoorsaqib/PDFUtens.git
```

Go into the project

```bash
cd PDFUtens
```

Create a virtual environment

```bash
python -m venv venv
```

Activate it

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
